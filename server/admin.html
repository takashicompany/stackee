    指示文

    両方のタブの指示文を保存します。変更のないタブは送りません。

    保存だけでは会話に反映されません。「保存して反映」で会話プロセスを再起動し、新しい設定と指示文を読み込みます。 会話履歴は Codex と Claude で別々です。切り替えて戻ると、それぞれ前の続きから再開します。 上の「会話をリセット」はその種別の会話だけを捨て、次の発話から新しい会話を始めます。

    独自キー (CSTM_0〜CSTM_9)

    保存するとすぐ有効になります (次の押下から)。 プロンプト: その文を会話エージェントに送り、返答を stackee が話します (写真を見せる時と同じ会話)。 コマンド: このサーバーで /bin/sh -c で実行します。作業場所は会話エージェントと同じフォルダ、 環境変数 STACKEE_KEY に押したキー名が入ります。 話させたい時はコマンドの中で stackee-say "テキスト" (字幕だけなら stackee-say --no-voice "テキスト") を呼びます。 コマンドが終わるまで次の会話・キーは受け付けません。時間切れは最大600秒です。
