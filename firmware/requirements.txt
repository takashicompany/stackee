# Stackee — ホスト側 (自分の PC) の Python パッケージ。
#
#   python3 -m pip install --user -r firmware/requirements.txt
#   (まとめて用意するなら firmware/setup.sh。README §0-0)
#
# ★ ここに書いてあるのは **tools/ の道具**が使うもので、ファームのビルドには
#   一切要らない。ビルドに要る Python は ESP-IDF が install.sh で自分の venv に
#   入れる。ホストのテスト (tools/test_*.py) も標準ライブラリと cc だけで動く
#   (足りないものがあるテストは自分で skip する)。
#
# どれがどの道具に要るかは README §2 の表と同じ:
#
#   esptool   flash.py / write_image.py / nvs_dump.py / pmic_cycle.py
#             — ROM ダウンロードモードのフラッシュ読み書き。v5 系の API
#               (esptool.targets.esp32s3.ESP32S3ROM) を直に呼んでいる
#   pyserial  console_hid.py (--transport serial) / flash.py / fs_put.py /
#             check_phase*.py — CDC のコンソールと 1200 bps タッチ
#   pyusb     flash.py — ROM に居るか / アプリが USB に戻ったかを VID:PID で見る。
#             無くても動くが、バスリセットの手当てが効かなくなる
#   hid       console_hid.py (--transport hid) / test_hid_report_map.py —
#             Raw HID のコンソール。full プロファイルだとこれしか経路が無い。
#             ★ C ライブラリ本体は pip では入らない:
#                 macOS   brew install hidapi
#                 Ubuntu  sudo apt-get install -y libhidapi-hidraw0
#   Pillow    import_faces.py / gen_font16.py の --check — 元絵と素材の突き合わせ
#   bleak     check_ble.py — BLE の広告と GATT を読むだけの確認
#
# 版は「これ以降」だけ書いてある。実際に動かして確かめた組み合わせは
# esptool 5.3.0 / pyserial 3.5 / pyusb 1.3.1 / hid 1.0.9 / Pillow 12.2.0 /
# bleak 3.0.2 (macOS 26 + CPython 3.11)。
